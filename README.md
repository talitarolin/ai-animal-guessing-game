# Animal Guessing Game 🐾

A Python practice project developed as part of Stanford Code in Place to explore conditional logic, user input, and AI integration.

## About

This program asks the user to think of an animal, provide a short description, and lets an AI model try to guess it. The program then compares the AI's guess with the animal entered by the user.

## Concepts Practiced

- User input with `input()`
- Variables and f-strings
- Conditional statements (`if/else`)
- String comparison
- Prompt design for AI interaction
- Python program structure and the `main()` function

## Technologies

- Python
- Stanford Code in Place AI module (`ai`)

## Environment

This project is developed and tested in the Stanford Code in Place environment.

The `ai` module is provided by the course environment and is not included in this repository. Therefore, the program is not currently configured to run locally on my computer.
